# NovaChaos

NovaChaos is a Chrome extension that transforms any webpage into a chaotic physics playground. Page elements break free, respond to gravity and repulsion, and you try to catch them before they escape.

## Features

- Turn any normal webpage into a playable chaos field
- Physics controls: gravity, repulsion, intensity
- Multiple modes / presets
- Catch escaping elements
- Session stats and best time tracking
- Popup control panel
- Works across normal browser tabs

## How To Use

1. Install the extension (Load unpacked)
2. Open any normal webpage
3. Open the NovaChaos popup
4. Start chaos mode
5. Catch elements and experiment with different presets

## Notes

- Does not work on protected browser pages (`chrome://`, extension store pages, etc.)
- Built as a fun boredom / idle-tab toy, not a productivity tool

## Tech Stack

- Chrome Extension (Manifest V3)
- React + TypeScript
- Content script physics interaction

## Purpose

A playful browser toy for short idle sessions — like a desktop pet, but for any tab.
